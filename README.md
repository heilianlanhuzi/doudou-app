# 豆豆的家（Doudou App）

第一阶段：可在 iPhone Safari 打开的 PWA 交互原型。

## 当前已有
- 首页信息架构与底部导航
- 闹钟时间设置界面（本地保存设置）
- 闹钟启用/关闭开关
- 房间主题入口与豆豆互动反馈
- PWA manifest 与离线缓存基础

## 重要限制
当前闹钟只是界面和本地设置演示，不会在 iOS 后台准时响铃，也没有系统通知/音频唤醒能力。当前房间为临时 CSS 示意，尚未接入正式豆豆母版和家具 PNG。后续必须替换为用户确认的原始美术资产，不能重新生成角色。

## 本地预览
直接通过静态网页托管发布。iPhone Safari 打开站点后，可通过分享菜单“添加到主屏幕”体验。
